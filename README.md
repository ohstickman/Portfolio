## 1. Консольная версия Cyber Grind.

### Управление
- Хождение на **W/A/S/D**
- Чтоб убить врага нужно встать на его клетку
- Чтоб подобрать аптечку нужно встать на нее

### Интерактив
- **4** вариации комнат
- Максимальное количество убийств сохраняется в `stats.txt`
- Бесконечно врагов

**Инструменты:** `C++`

## 2. 2д версия Cyber Grind.

### Управление
- Хождение **W/A/S/D**
- Для убийства врага надо нанести ему **75 хп**
- Для атаки - **SPACE**
- Для подбора аптечки надо коснуться ее

### Интерактив
- **2** вариации комнаты
- Максимальное количество убийств сохраняется в `stats.txt`
- Анимации:
  - урона
  - атаки
  - исцеление
- Бесконечно врагов

**Инструменты:** `C++`, `raylib`

## 3. 3д Редактор примитивов

### Управление
- для вращения по орбите **ЛКМ** + вращение мышкой
- для приближения отдаления **ЛКМ** + колесико мыши
- для нажатия кнопки - **ЛКМ**
- для ползунком - **ПКМ**

### Функционал
- Фигуры:
  - Куб
  - Сфера
  - Круг
- Кнопка включения каркаса
- Настройки:
  - Размер **XYZ** для куба
  - Радиус и размер сетки сферы
  - Радиус круга
  - Расстояние и разрезы основной сетки

**Инструменты:** `C++`, `raylib`
